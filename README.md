Vegetable Shop Management System
A simple Python console application designed to simulate a vegetable shop's functionality, featuring a login system, inventory management, cart system, and billing process. This project demonstrates key programming concepts such as loops, conditional statements, and user interaction handling.

Features
Login System: User authentication with a simple username and password check.

Vegetable Inventory: View available vegetables, their prices, and stock quantities.

Cart Management: Add items to the cart, manage stock, and update quantities.

Billing and Checkout: Calculate total bill with discounts and GST based on the cart contents.

Stock Updates: Automatic stock deduction upon adding items to the cart.

Simple Interface: Text-based interface using Python, designed for easy navigation and interaction.

Technologies Used
Python: Core programming language used to develop the application.

Basic Programming Concepts: Loops, conditionals, lists, and user input handling.
